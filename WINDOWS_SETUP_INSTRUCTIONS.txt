If the automated script fails, follow these manual steps:

A) Install PulseAudio for Windows:

   Option 1: Using winget
   ----------------------
   winget install --id=PulseAudio.PulseAudio -e

   Option 2: Manual download
   -------------------------
   1. Visit: https://www.freedesktop.org/wiki/Software/PulseAudio/Ports/Windows/Support/
   2. Download the latest pulseaudio-x.x.zip
   3. Extract to C:\PulseAudio


B) Configure PulseAudio:

   1. Create directory: C:\PulseAudio\etc\pulse
   2. Create file: C:\PulseAudio\etc\pulse\default.pa
   3. Add this content to default.pa:

      load-module module-native-protocol-tcp auth-ip-acl=127.0.0.1;172.16.0.0/12
      load-module module-esound-protocol-tcp auth-ip-acl=127.0.0.0/8
      load-module module-waveout sink_name=output source_name=input record=0


C) Start PulseAudio:

   cd C:\PulseAudio\bin
   .\pulseaudio.exe

   (Leave this window open! PulseAudio must keep running)


D) Configure Windows Firewall (if needed):

   1. Open Windows Defender Firewall
   2. Click "Allow an app through firewall"
   3. Click "Change settings"
   4. Click "Allow another app..."
   5. Browse to: C:\PulseAudio\bin\pulseaudio.exe
   6. Add it and check both Private and Public
