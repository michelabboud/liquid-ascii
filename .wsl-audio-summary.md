# 🔊 WSL Audio Issue - Complete Solution Guide

## Why Can't You Hear Audio in WSL?

**Simple answer:** WSL (Windows Subsystem for Linux) is a Linux environment running on Windows, but it doesn't have direct access to Windows audio hardware by default.

Think of it like running Linux in a container - it can run Linux programs, but it's isolated from Windows audio devices.

### 2. 🥈 Automated WSL Audio Fix (MEDIUM - 5 minutes)

**Bridge WSL audio to Windows audio system.**


This configures WSL to use the Windows audio server.

## 🔧 Quick Fixes

### "PulseAudio not found on Windows"

```powershell
# In Windows PowerShell
winget install --id=PulseAudio.PulseAudio -e
```

### "Connection refused" in WSL

```bash
# Check if PulseAudio is running in Windows
# In PowerShell:
Get-Process pulseaudio

# If not running:
cd C:\PulseAudio\bin
.\pulseaudio.exe
```

### "PULSE_SERVER not set" in WSL

```bash
export HOST_IP=$(cat /etc/resolv.conf | grep nameserver | awk '{print $2}')
export PULSE_SERVER=tcp:$HOST_IP
./dev.sh run --speak "Testing"
```

### "Still no audio!"

**Just use Windows PowerShell!** Seriously, it's easier:

## 💡 Understanding the Architecture

```
┌─────────────────────────────────────────────────────┐
│                    WINDOWS                          │
│  ┌──────────────────────────────────────────────┐  │
│  │          Windows Audio Hardware               │  │
│  └───────────────────▲──────────────────────────┘  │
│                      │                              │
│  ┌───────────────────┴──────────────────────────┐  │
│  │  Option 1: Windows PowerShell (Native)       │  │
│  │  .\scripts\dev.ps1 run --speak "Hi"          │  │
│  │  → Works directly ✅                          │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
│  ┌──────────────────────────────────────────────┐  │
│  │  Option 2: PulseAudio Server (Bridge)       │  │
│  │  C:\PulseAudio\bin\pulseaudio.exe            │  │
│  └───────────────────▲──────────────────────────┘  │
│                      │                              │
│                      │ Network Connection (TCP)     │
│  ┌───────────────────┴──────────────────────────┐  │
│  │              WSL Environment                  │  │
│  │  ./dev.sh run --speak "Hi"                   │  │
│  │  → Needs PulseAudio bridge ⚠️                 │  │
│  └──────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

**Key insight:** WSL needs a "bridge" (PulseAudio) to reach Windows audio. Windows PowerShell connects directly.
